This is README file for Rock Paper Scissors App

Pseudocode:
1.Request the user to choose Rock, Paper, or Scissors.
2.Define a variable to store the user's choice.
3.Generate a random choice for the computer between Rock, Paper, and Scissors.
4.Store the random choice in a variable.
5.Check the user's and computer's choices and determine the conditions for the winner.
6.Display both choices and determine the winner.
